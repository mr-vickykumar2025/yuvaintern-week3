# Open Pages — Week 3 Accessibility Project

A responsive blog / information portal demo focused on accessibility and user experience.

## Quick start
Open `index.html` in a modern browser. No installation is needed.

## Files
- `index.html` — semantic page structure and content
- `styles.css` — responsive styling, visible focus, and reduced-motion support
- `script.js` — accessible mobile menu and article search
- `REPORT.md` — project report, accessibility checklist, standards mapping, and audit instructions

See `REPORT.md` for the full documentation and suggested Lighthouse/WAVE audit procedure.
